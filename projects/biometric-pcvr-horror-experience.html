( contribution )

What I worked on

My work focused on turning noisy EMG input into something that felt usable in-game. That meant assembling the sensing setup, testing different muscle actions, reviewing false triggers and refining how gameplay events were fired and reset.

  • Built and assembled the EMG sensing hardware used by the project.
  • Tested rest-state fluctuation, false positives, missed detections and repeated contractions.
  • Adjusted threshold and reset logic so the interaction became more dependable.
  • Connected sensor-driven events with PCVR gameplay, fallback controls and the broader experience flow.

Input Flow

Muscle Activity → EMG Sensor → Arduino → Unity

Testing Lens

Observe → reproduce → adjust → retest until interaction felt reliable.
