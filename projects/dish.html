( contribution )

What I worked on

My contribution sat between the system layer and the player-facing feel of the app. I worked on backend routes, database and SQL logic, then also contributed some front-end interaction polish to support the app's gamified tone.

  • Built and supported backend flows for auth, profile, feed, recommendations and reviews.
  • Worked on the database structure and SQL logic behind user state, uploads and progression.
  • Contributed UI details such as click feedback, gamified effects and interaction polish.
  • Helped connect content, profile customisation and XP logic into one experience loop.

App Stack

Express → MySQL → SQL → UI

Contribution Lens

Backend stability, data structure and small interaction moments that made the product feel more playful.
